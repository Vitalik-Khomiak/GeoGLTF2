# GeoGLTF Viewer

Дипломний проект 2026 ArtLab.

Дата в рядку «Оновлення коду» береться з константи `BUILD_DATE` у `src/app.js`. Її треба піднімати вручну разом із версією кеша в `sw.js` — застосунок навмисно не робить жодного запиту за межі власної адреси.

Статичний веб-переглядач `.glb` моделей для навчальних сценаріїв з математики. Додаток побудований на `HTML + CSS + JavaScript + Three.js`, підтримує локальне завантаження 3D-моделі, координатну сітку, осі `X/Y/Z`, обертання, панорамування, масштабування та бібліотеку моделей для швидкого перемикання.

Інструменти просторового аналізу: інтерактивний переріз площиною з площею і периметром, підписи вершин, лінійка відстаней, підсвічування граней, характеристика Ейлера `В−Р+Г`, анімовані розгортки (куб, паралелепіпед, піраміди, призми, циліндр, конус), експорт вершин у GeoGebra, авто-обертання, швидкі види камери, знімки PNG, прямі посилання на модель і офлайн-режим (PWA).

## Для чого це

Інструмент розрахований на початок роботи з темою стереометрії. Учень
відкриває фігуру з телефона за посиланням або QR, обертає її, дивиться
з різних боків і вмикає режим, у якому модель виглядає так само, як
рисунок в аксонометрії у підручнику. Таким чином встановлюється зв'язок
між об'ємним тілом і його плоским зображенням — місце, де стереометрія
для багатьох учнів і зупиняється.

Побудов застосунок свідомо не робить: не дає задавати точки, проводити
прямі й площини за умовою задачі. Це роль динамічної геометрії
(GeoGebra 3D), і поділ ролей зроблено навмисно. Тут — первинне
спостереження з нульовим порогом входу: нічого не треба встановлювати
чи реєструвати. Вимірювання є (лінійка, площа й периметр перерізу), але
як перевірка здогаду, а не як мета.

Поодинокий перегляд моделі мислення не розвиває. Працює послідовність:
учень спершу записує передбачення, потім перевіряє його на моделі,
а потім пояснює, чому результат саме такий. Тому кожна модель у бібліотеці
має навчальне запитання, що показується в картці.

## Швидкий запуск локально

Найпростіше — подвійний клік на `start.bat`. Він сам підніме локальний сервер
і відкриє застосунок у браузері. Щоб зупинити — закрийте вікно сервера.

Потрібен лише встановлений Python (під час встановлення має бути позначено
«Add Python to PATH»). Якщо його немає, лаунчер про це скаже.

Вручну, якщо зручніше:

1. Відкрийте PowerShell у каталозі проєкту:

```powershell
cd path\to\GeoGLTF
```

2. Запустіть простий локальний сервер:

```powershell
python -m http.server 8000
```

3. Відкрийте у браузері:

[http://localhost:8000](http://localhost:8000)

> Важливо: додаток використовує ES-модулі, тому відкривати `index.html` напряму через `file://` не варто. Потрібен локальний веб-сервер.

### Посилання на конкретну модель

Щоб учень одразу потрапив на потрібну фігуру, а не в загальну бібліотеку,
додайте до адреси параметр `?model=`:

```
https://vitalik-khomiak.github.io/GeoGLTF2/?model=cube
https://vitalik-khomiak.github.io/GeoGLTF2/?model=tetrahedron
https://vitalik-khomiak.github.io/GeoGLTF2/?model=cones_similar
```

Підходить і назва моделі з `library.json`, і імʼя файлу. Кирилична назва теж
працює (`?model=куб`), але в адресі вона кодується у довгий нечитабельний
рядок, тому для друку й QR зручніше імʼя файлу латиницею.

Готове посилання на поточну модель формує кнопка `Поділитися` у режимі
перегляду — його зручно перетворити на QR-код і роздати класу.

### Конкретний переріз у посиланні

Параметр `?sec=` відтворює положення січної площини: вісь, зсув, нахил, поворот.

```
https://vitalik-khomiak.github.io/GeoGLTF2/?model=cube&sec=y,0,54.7,45
```

Це приклад із правильним шестикутником у перерізі куба. Кути дробові, тому
вгадати їх повзунками важко — посилання лишається єдиним практичним способом
роздати класу конкретний переріз. Кнопка `Поділитися` дописує `sec`
автоматично, коли переріз увімкнено.

Зсув задається у відсотках радіуса описаної сфери моделі від її центру, а не
в одиницях сцени. Для широких моделей із двома тілами радіус більший за їхню
висоту, тому великі значення зсуву виводять площину за межі фігури.

### Режим «Спершу передбач»

Параметр `?predict=1` ховає фігуру: спершу показується запитання до моделі,
і лише після кнопки з'являється сама фігура. Панель інструментів на цей час
недосяжна, щоб числа й розгортка не підказували відповідь.

```
https://vitalik-khomiak.github.io/GeoGLTF2/?model=cube&predict=1
```

Працює рівно `?predict=1`. Написання `?predict` або `?predict=true` мовчки
не спрацює. Параметри поєднуються: `?model=cube&sec=y,0,54.7,45&predict=1`.

## Як зробити пачку 3D-асетів

1. Поклади свої `.glb` моделі в папку `assets/models/`.
2. Опиши їх у файлі `assets/library.json`.
3. Після деплою ці моделі з’являться у блоці `Опублікована колекція`, і кожен учень зможе обирати, яку модель крутити.

Приклад `assets/library.json`:

```json
{
  "assets": [
    {
      "title": "Куб",
      "description": "Модель для теми об'єму та площі поверхні",
      "file": "./assets/models/cube.glb",
      "sizeLabel": "320 KB"
    },
    {
      "title": "Призма",
      "description": "Модель для вправ із просторового мислення",
      "file": "./assets/models/prism.glb"
    }
  ]
}
```

Окремо є `Локальна колекція`: якщо додати кілька файлів через кнопку або drag-and-drop, вони теж з’являться в списку, але лише на час поточної сесії браузера.

## Інтеграція з GeoGebra

Кнопка `GeoGebra ⤴` у режимі перегляду вже реалізована. Вона:

1. Збирає кутові вершини многогранника з геометрії моделі (через `EdgesGeometry` у світових координатах).
2. Підписує їх так само, як інструмент `Підписи`: `A, B, C…` для нижньої основи, `A_1, B_1…` для верхньої, `S` для вершини піраміди.
3. Формує команди GeoGebra і копіює їх у буфер обміну:

```
A=(-1.000,0.000,-1.000)
B=(1.000,0.000,-1.000)
A_1=(-1.000,2.000,-1.000)
```

4. Далі достатньо вставити ці рядки у рядок вводу GeoGebra (Полотно 3D) — точки з'являться на сцені.

Наступним кроком можна додати:

- живу синхронізацію через `ggbApplet.evalCommand(...)` у вбудованому аплеті;
- експорт ребер як відрізків (`Segment(A,B)`) і граней як многокутників (`Polygon(...)`);
- синхронізацію вибраної вершини між Three.js-сценою та GeoGebra 3D.

## Авторство і сторонні компоненти

### Код застосунку

`index.html`, `styles.css`, `src/app.js`, `sw.js`, `manifest.webmanifest`,
`tools/` — авторський код. Ліцензія MIT, текст у файлі [LICENSE](LICENSE).

### Бібліотека

`assets/vendor/three/` — Three.js ревізії r161, локальна копія офіційного
пакета `three@0.161.0`. Раніше бібліотека вантажилася з CDN; локальна копія
потрібна для офлайн-режиму.

Це стороннє програмне забезпечення, до авторського коду застосунку воно не
входить. Ліцензія MIT, права належать авторам Three.js; текст ліцензії —
[assets/vendor/three/LICENSE](assets/vendor/three/LICENSE).

### Моделі

П'ятнадцять `.glb`-файлів у `assets/models/`. Нижче — інструмент виготовлення
кожного, за метаданими самих файлів (поле `asset.generator`):

| Файл | Інструмент виготовлення |
|---|---|
| `cube.glb`, `cube_slice.glb`, `Cylynder.glb`, `Piramide.glb` | Blender, експорт Khronos glTF Blender I/O v5.0.21 |
| `cone.glb`, `prism_tri.glb`, `prism_hex.glb` | скрипт на бібліотеці trimesh (Python) |
| `parallelepiped.glb`, `prism_square.glb`, `prism_tri_slice.glb`, `pyramid_square.glb`, `tetrahedron.glb`, `cylinders_pair.glb`, `cones_similar.glb` | `tools/make-models.mjs` — авторський генератор із цього репозиторію |
| `sphere.glb` | скрипт-генератор |

Поле `asset.copyright` у метаданих усіх п'ятнадцяти файлів порожнє.

Тіла, зроблені `tools/make-models.mjs`, описані в самому скрипті й
відтворюються командою `node tools/make-models.mjs`. Їхні розміри входять
в умови навчальних завдань, тому перевіряються числами:
`node tools/check-models.mjs`.
